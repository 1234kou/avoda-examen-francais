AVODA ACADÉMIE — PARCOURS FRANCE
Mini-application mobile légère, prête pour un hébergement statique sur Render.

Fichiers :
- index.html : application
- manifest.webmanifest : installation mobile/PWA
- icon.svg : icône AVODA provisoire
- og-parcours-france.png : couverture d'aperçu WhatsApp
- render.yaml : configuration Render

Important : l'icône actuelle est une identité AVODA typographique (A). Si vous fournissez
le logo officiel AVODA, il pourra remplacer l'icône sans modifier l'application.
